# Third-party components

MediaPipe Tasks Vision runtime and WASM are bundled in `extension/vision/`. See `extension/vision/package-metadata.json` and `README-mediapipe.md` for the pinned package and upstream source. The Apache-2.0 text is bundled in `licenses/MediaPipe-Apache-2.0.txt`. MediaPipe source license: https://github.com/google-ai-edge/mediapipe/blob/master/LICENSE

The bundled face landmark, hand landmark and selfie multiclass segmentation model assets came from Google's MediaPipe model distribution. Model-specific redistribution terms must be confirmed before this private beta is made public.

Krea and fal are external services and are not bundled software. YouTube, Chrome and Comet are third-party products. This project is unaffiliated with them.

The initial MeTube extension was provided as a local ZIP. Its original authorship and license have not been established in this repo. Keeping this beta private does not establish a right to redistribute it publicly.
